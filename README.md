# Serverless Chatbot for Customer Support
Serverless customer support chatbot using Amazon Lex, AWS Lambda, API Gateway, and Amazon Cognito.

## Project Overview

This project implements a serverless chatbot for customer support using AWS services.

The chatbot can understand user queries and provide automated responses without requiring a dedicated server.

## AWS Services Used

- Amazon Lex – Natural language understanding and chatbot
- AWS Lambda – Backend processing
- Amazon API Gateway – API communication
- Amazon Cognito – User authentication

## Features

- Automated customer support
- Natural language interaction
- Serverless backend
- User authentication
- API-based communication
- Scalable architecture

## Technologies

Python, Amazon Lex, AWS Lambda, API Gateway, Amazon Cognito, HTML, CSS, JavaScript

## Architecture

User

Frontend
↓
